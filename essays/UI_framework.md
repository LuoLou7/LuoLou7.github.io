## What are UI Frameworks
   UI Frameworks are software with pre-built components and application structures that make implementing and developing applications efficient. There are many UI frameworks out there, and choosing which UI framework to use depends on what type of application you are creating. Some of the most popular UI frameworks for Web applications are React, Angular, Vue, and Bootstrap. And for mobile applications, there are SwiftUI, Flutter, and React Native. 

## UI Frameworks Key Features
  Why use UI frameworks? 
  
  UI frameworks has a lot of benefit. First, because code are already pre-written it cuts the development time significantly, saving software engineers a lot of time. Lots of developers and companies use frameworks because of this. Frameworks are also very secure, and using them can reduce bugs in your code. Another reason as to why UI frameworks are widely used is because of device compatibility. When using UI frameworks, the code behaves the same on different devices and automatically handles different screen layouts. This ensures that the code functions and looks similar across different devices. 


## Thoughts on UI Frameworks
  Before this class, I had not really used any type of UI framework. I only coded in HTML, CSS, and JavaScript when creating Web Applications. At first, I didn't know how useful Bootstrap actually is. Since I wasn't that familiar and I'm still getting used to it, there where times where I would just use CSS to modify little things instead of using Bootstrap. After using Bootstrap a few times and creating a few websites for an assignment in this class, I realized how much it makes web development simpler. For example, a fully responsive navbar can be developed in just a few lines, and you don't have to create everything from scratch. Some designs are also pre-built which makes it easy to modify a design and sometimes it only takes one line of code instead of modifying each component with CSS, which takes a lot of time.

  
## Conclusion
   UI Frameworks can be complicated and can have a huge learning curve; however, once you became familiar with it, it will make development way simpler. Since things are already pre-built, you don't have to code them yourself unless you want the design to be custom. This saves developers a lot of time and makes development move faster. It doesn't just make things efficient but also consistent, which makes User Interfaces more put together and look well designed in way less time. There are also other benefits to using a UI framework, such as browser and device compatibility and making codebases standardized. Overall, there are a lot of benefits in using UI frameworks and learning how to use them is very essential.
