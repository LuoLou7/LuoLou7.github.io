*What are UI Frameworks*
  UI Frameworks are software with pre-built components and application structure that makes implementing and developing applications efficient. There are many UI frameworks out there and choosing which UI framework to use depends on what type of application you are creating. Some of the most popular UI framework for Web applications are React, Angular, Vue, and Bootstrap. 

*Thoughts on UI Frameworks*
    Before this class I have not really used any type of UI frameworks before. I only coded in HTNL, CSS, and JavaScript when creating Web Applications. At first I didn't know how useful Bootstrap actually is. Since I wasn't that familiar and I'm still getting used to it, there where times where I would just use CSS to modify little things instead of using Bootstrap. After using Bootstrap a few times creating the practice websites, I realize how it makes web development simpler. For example, a fully responsive navbar can be develop in just a few lines and you don't have to create everything from scratch. Some designs are also pre-built and instead of modifying each component with CSS, which takes a lot of time, it can be modified with one line. 

  *Conclusion* 
    UI Frameworks can be complicated and a huge learning curve, however once you became familiar with it, it will make development way simpler. Since things are already pre-built, you don't have to code them yourself unless you want them to custom. This saves developers a lot of time and make development move faster. It doesn't just make things efficient but also consistent which makes User Interfaces more put together and look well designed in way less time. There are also other benefits with using UI framework such as browser and device compatibility and making codebases standardized.
